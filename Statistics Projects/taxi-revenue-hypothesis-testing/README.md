# Taxi Revenue Optimization Using Hypothesis Testing
### Project Overview

This project analyzes NYC Yellow Taxi trip data to identify revenue-driving factors and evaluate whether payment type (Cash vs Credit Card) significantly impacts total fare amount.

Using statistical hypothesis testing, the objective is to provide data-driven recommendations to maximize taxi driver revenue.

### Business Problem

Taxi drivers want to understand:

Does payment type influence the total revenue generated per trip?

If a significant difference exists, drivers can optimize payment preferences to maximize earnings.

### Dataset

Dataset: NYC Yellow Taxi Trip Data (January 2020)

Features Used:

Trip Distance

Pickup & Dropoff Time

Payment Type

Fare Amount

Total Amount

### Key Insight

Statistical testing revealed a significant difference in revenue between payment types.

Results support data-backed decision-making for revenue optimization strategies.

### Statistical Approach

Null Hypothesis (H₀): No difference in average revenue between payment types

Alternative Hypothesis (H₁): Significant difference in average revenue

Significance Level (α): 0.05
