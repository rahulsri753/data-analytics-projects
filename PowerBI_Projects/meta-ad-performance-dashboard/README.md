# Meta Ad Performance Dashboard (Power BI)

### Project Overview

This project analyzes Meta (Facebook) advertising campaign performance using Power BI to track key marketing KPIs and evaluate campaign effectiveness.

The dashboard provides actionable insights into ad spend, conversions, ROI, CTR, CPC, and overall campaign performance to support data-driven marketing decisions.

### Business Objective

Marketing teams want to understand:

Which campaigns generate the highest ROI?

Which ads drive maximum conversions?

How efficiently is ad budget being utilized?

What factors impact campaign performance?

This dashboard helps stakeholders optimize advertising spend and maximize returns.

### Key Metrics (KPIs)

Total Ad Spend

Total Impressions

Click-Through Rate (CTR)

Cost Per Click (CPC)

Conversions

Cost Per Conversion

Return on Investment (ROI)

### Tools & Technologies Used

Power BI

DAX (Data Analysis Expressions)

Data Modeling

Data Cleaning & Transformation

Interactive Dashboard Design

### Dashboard Features

Campaign-level performance comparison

ROI & conversion trend analysis

Spend vs Return visualization

Interactive filters & slicers

KPI cards for executive summary

### Business Insights

Identified high-performing campaigns generating maximum ROI

Detected campaigns with high spend but low conversion efficiency

Provided recommendations to reallocate marketing budget toward high-performing ads
