# Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, high-value customers, and revenue-driving factors.

Using Python for data analysis, SQL for querying insights, and Power BI for interactive visualization, this project demonstrates an end-to-end data analytics workflow.

### Business Objective

Retail businesses want to understand:

Which customers generate the highest revenue?

What products sell the most?

What are the key purchasing patterns?

How can businesses increase repeat purchases?

Which customer segments are most profitable?

This analysis provides data-driven insights to improve sales strategy and customer retention.
