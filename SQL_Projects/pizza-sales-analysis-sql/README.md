# Pizza Sales Performance & Revenue Analysis using SQL
### Project Overview

This project focuses on analyzing a Pizza Hut sales dataset using MySQL to extract meaningful business insights.

The objective was to evaluate sales performance, customer ordering behavior, revenue trends, and product popularity using SQL queries.

### Business Problem

The business wants to understand:

How much total revenue is generated?

Which pizzas generate the highest revenue?

What are the peak ordering hours?

Which pizza categories contribute most to sales?

What is the daily average demand?

How revenue grows over time?

### Database Structure

The analysis was performed using the following tables:

orders

order_details

pizzas

pizza_types

The database was created and managed using MySQL.

### SQL Concepts Used

✅ Aggregate Functions (SUM, COUNT, AVG)

✅ GROUP BY & ORDER BY

✅ JOINS (Inner Join)

✅ Subqueries

✅ Window Functions (RANK, SUM OVER)

✅ Revenue Calculation Logic

✅ Percentage Contribution Analysis

✅ Cumulative Revenue Trend Analysis

### Sales & Revenue Analysis

### Customer Behavior Analysis

Identified most common pizza size ordered

Calculated average pizzas ordered per day

### Product Performance

Top 5 most ordered pizza types

Category-wise total quantity ordered

Distribution of orders by hour

Cumulative revenue growth over time
