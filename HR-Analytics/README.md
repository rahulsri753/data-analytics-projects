# HR Analytics Dashboard

## Project Overview

This project demonstrates an end-to-end HR Analytics solution using **Python, SQL, and Power BI** to analyze employee data and generate actionable workforce insights. The objective is to help HR teams monitor workforce trends, employee attrition, recruitment performance, and organizational KPIs through an interactive dashboard.

---

## Business Objective

The goal of this project is to transform raw HR data into meaningful insights that support data-driven HR decisions related to:

* Workforce Planning
* Employee Attrition Analysis
* Recruitment Performance
* Employee Demographics
* Salary Analysis
* Performance Monitoring
* Employee Satisfaction

---

## Tools & Technologies

* Python (Pandas, NumPy)
* SQL (MySQL)
* Power BI
* Microsoft Excel

---

## Project Workflow

### 1. Data Cleaning (Python)

* Cleaned and prepared HR datasets for analysis.
* Handled missing values and inconsistent records.
* Corrected data types and formatted fields.
* Performed data preprocessing for reporting.

### 2. Exploratory Data Analysis (Python)

* Analyzed employee demographics.
* Examined salary distribution.
* Evaluated employee satisfaction.
* Identified attrition patterns.
* Explored department-wise workforce distribution.

### 3. SQL Analysis

Performed SQL analysis using:

* Joins
* Aggregate Functions
* GROUP BY
* CASE Statements
* Common Table Expressions (CTEs)
* Window Functions

to extract workforce insights and support KPI reporting.

### 4. Power BI Dashboard

Developed an interactive HR dashboard to monitor key workforce metrics and enable dynamic analysis using filters and visualizations.

* Performance Rating
* Workforce Diversity

---

# Key Insights

* Analyzed workforce data for **311 employees**.
* Identified an **Attrition Rate of 33%**.
* Found the **Production Department** had the highest workforce.
* Identified **Indeed** and **LinkedIn** as the top recruitment sources.
* Compared employee performance, satisfaction, salary, and tenure across departments.
* Built interactive visualizations to support HR reporting and workforce planning.
